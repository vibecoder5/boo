# Руководство пользователя boo

boo — программа для чтения книг на своём компьютере. Книги, закладки и заметки никуда не отправляются.

## Установка

На Windows запустите `boo-setup.exe`. Программа ставится для вашего пользователя, ярлык появляется в меню «Пуск». По желанию можно открывать файлы EPUB и FB2 двойным щелчком.

Удаление — из списка программ Windows. Книги, закладки и заметки в `%AppData%\boo` останутся.

## Запуск

1. Запустите boo из меню «Пуск» или файл `boo.exe` (из исходников — `go run .`).
2. На Windows откроется окно читалки. Если окна нет — установите [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) или запустите с флагом `-web`.
3. При запуске из терминала в консоли появится адрес вида `http://127.0.0.1:7474/`. Обычно его открывать не нужно.

Полезные варианты:

```text
boo.exe книга.fb2          открыть файл сразу
boo.exe -demo              встроенная демо-книга
boo.exe -web               браузер вместо окна
boo.exe -no-open           только сервер
```

Закрытие окна на Windows останавливает программу. В режиме браузера сервер работает, пока не остановите процесс в терминале.

## Полка

Стартовый экран — полка текущего рабочего пространства: один ряд из пяти книг, сразу под верхним меню. Слева — меню с переносом библиотеки и настройками шрифтов. Справа — списки для чтения и рабочие пространства.

- **Открыть** в верхней панели, **+** на полке или свободный слот — окно добавления книги.
- В окне можно выбрать EPUB, FB2, ZIP, TXT или Markdown, открыть демо-книгу или это руководство.
- **Руководство** в шапке или клавиша `F1` — открыть этот текст в читалке.
- Правый клик по пустому месту полки — открыть файл, демо-книгу или руководство.
- Клик по обложке — продолжить чтение с сохранённого места.
- Правый клик по книге — прочитана / непрочитана, описание, список дел, добавить в список, перенести в другое пространство.

boo копирует файл в свою библиотеку. Исходник можно потом перенести — копия останется.

Кнопка **Полка** в читалке возвращает на этот экран, не закрывая прогресс.

## Рабочие пространства

Пространства — отдельные полки (например «Дом» и «Учёба»). У каждого свои книги, списки, закладки и история. Список пространств — в правой панели на полке.

- **Пространства** в шапке, полоска справа или клавиша `W` — показать или скрыть панель. Ширину можно потянуть за край.
- **Создать** — новое пустое пространство, оно сразу становится текущим.
- **Переименовать** — имя текущего пространства (до 80 символов).
- Клик по карточке — переключение. Открытая книга закрывается, сессия пишется в историю.
- Правый клик по книге → выбрать пространство или вписать новое имя. Книга уходит с текущей полки вместе с прогрессом, закладками и заметками. Файл и обложка общие, текущее пространство не меняется.

Настройки оформления (тема, шрифты) общие для всех пространств. Словари тоже общие, но привязка словаря к книге хранится в пространстве.

Одна и та же книга может быть на нескольких полках: файл и обложка общие, прогресс и заметки — свои.

## Списки для чтения

На полке можно собрать подборки («На отпуск», «Учебники»). Списки — в правой панели рядом с пространствами.

- **Списки** в шапке, полоска справа или клавиша `L` — показать или скрыть панель. Ширину можно потянуть за край.
- **Создать** — новый список.
- Правый клик по книге → выбрать список или вписать новое имя.
- Клик по карточке списка фильтрует полку. Снова «Все книги» — снять фильтр.
- Двойной щелчок открывает экран списка: те же карточки с обложками, что на полке. **+** или пустой слот — выбрать книгу с полки или новый файл; файл тоже попадёт в список. Крестик на карточке убирает книгу из списка, не с полки. **← Полка** или Esc — назад.

Удаление списка не удаляет книги.

## Чтение

Открытая книга: текст по центру, слева меню, справа заметки и история.

- **← Предыдущая** / **Следующая →** или стрелки клавиатуры — главы.
- Полоса прогресса внизу — прыжок по текущей главе.
- В оглавлении клик по главе. Галочка «Отметить главу» или пункт в контекстном меню помечает главу прочитанной.
- **Скрыть прочитанные** убирает такие главы из оглавления (сами главы остаются в книге).
- **Поиск** в меню — до 40 совпадений, Enter открывает первое. Запрос не длиннее 80 символов.

Прогресс (глава и положение на странице) сохраняется сам. При следующем запуске boo откроет последнюю книгу полки.

### Меню слева

Кнопка **Меню** или клавиша `\`. На полке здесь перенос библиотеки и шрифты. В читалке — сведения о книге, большая заметка, прогресс, поиск, ширина страницы, шрифты, закладки, словари, оглавление.

Ширину колонки можно потянуть за край.

### О книге

Правый клик по тексту или по карточке на полке → **Описание и заметка**.

- **Описание** — коротко, до 2000 символов.
- **Большая заметка** — конспект на всю книгу, до 32 000 символов.

Текст пишется сам, без кнопки «Сохранить». В меню читалки та же большая заметка доступна сразу.

## Закладки, выделения, заметки

| Действие | Как |
| --- | --- |
| Закладка на текущем месте | **Закладка** в шапке, **Добавить** в меню или клавиша `B` |
| Цветное выделение | Выделить текст → в меню выбрать цвет |
| Заметка к фрагменту | Выделить текст → панель **Заметки** → **Добавить**, либо пункт в контекстном меню |
| Убрать выделение / заметку | Правый клик по фрагменту → **Убрать…** |
| Перейти к закладке или заметке | Клик по пункту в списке |

Цвета: жёлтый, зелёный, синий, розовый, оранжевый.

Панель заметок: кнопка **Заметки** или клавиша `N`. Наведите на пометку в тексте — всплывёт текст заметки.

Удаление закладки или заметки можно отменить (см. ниже).

## Словарь

1. В меню читалки откройте блок **Словарь** → **Подключить**.
2. Выберите файл: `.dsl`, `.xdxf`, `.json`, `.txt`, `.tsv`, `.dic`, `.xml`.
3. Наведите курсор на слово в тексте — если статья есть, появится перевод.

Поддерживаются словари Lingvo DSL, XDXF, JSON (`{"word": "перевод"}` или массив статей) и простые пары `слово<TAB>перевод` / `слово = перевод`.

До 24 словарей. Новый файл при открытой книге сразу привязывается к ней. Клавиша `D` включает и выключает словарь для текущей книги. Правый клик → **Перевести** по выделенному слову.

Удаление словаря отвязывает его от всех книг.

## Список дел

Правый клик по книге → **Список дел**. Нужны текст (до 400 символов), дата и время.

На полке блок дел относится к последней книге пространства. Отметьте пункт выполненным или удалите его. Срок обязателен. Если колонка полки достаточно широкая, список дел стоит слева, история и отмена — справа; на узком экране блоки идут друг под другом.

## История и отмена

**История** (клавиша `H` в читалке) показывает последние операции:

- сессии чтения (книга, глава, положение) — повтор в пределах двух минут обновляет ту же запись;
- свои отметки — поле «Своя отметка…».

Хранятся до 200 записей, на экране — последние 10.

**Отмена** возвращает:

- удалённую книгу (вместе с прогрессом, закладками, заметками и файлом, если он не нужен другой полке);
- удалённую закладку;
- удалённую заметку.

**Отменить последнее** или `Ctrl+Z` (`⌘Z` на macOS). Можно восстановить конкретную запись из списка «Удалённое». Журнал — до 50 действий в текущем пространстве.

Выделения из журнала отмены не восстанавливаются.

## Оформление

В левом меню на полке и в меню читалки:

- темы: тёмная → сепия → светлая (кнопка **Тема** или клавиша `T`);
- шрифт и размер текста книги (14–36);
- шрифт и размер интерфейса (12–24);
- ширина колонки текста (22–80).

Настройки общие для всех пространств и сохраняются сами.

## Перенос на другой компьютер

В левом меню на стартовом экране блок **Перенос**:

1. **Экспорт** — ZIP вида `boo-library-ГГГГ-ММ-ДД.zip`: книги, обложки, словари, прогресс, закладки, заметки, списки, пространства и настройки.
2. Скопируйте архив на другой компьютер.
3. **Импорт** — выберите ZIP.

Импорт **полностью заменяет** текущие данные boo. Открытая книга закроется. Сделайте экспорт, прежде чем импортировать чужой архив.

Лимит архива — порядка нескольких гигабайт. Нужен именно архив boo (`manifest.json` + `state.json`), не произвольный ZIP с книгами.

## Клавиши

Работают, когда курсор не в поле ввода.

| Клавиша | Действие |
| --- | --- |
| `←` `→` | Предыдущая / следующая глава |
| `[` `]` | Мельче / крупнее шрифт книги |
| `{` `}` | Уже / шире страница |
| `T` | Следующая тема |
| `B` | Закладка |
| `N` | Панель заметок |
| `H` | Панель истории |
| `W` | Панель пространств (на полке) |
| `L` | Панель списков (на полке) |
| `D` | Словарь вкл/выкл |
| `\` | Меню слева |
| `/` | Фокус в поиск |
| `Esc` | Закрыть подсказку, диалог, меню; экран списка; затем панели; затем выход на полку |
| `F1` | Руководство пользователя |
| `Ctrl+Z` | Отменить последнее удаление |
| `Enter` в поиске | Открыть первое совпадение |

## Если что-то не так

**Окно не открылось.** Установите WebView2 или запустите `boo.exe -web`.

**«Файл больше недоступен».** Книгу открывали с диска, копии в библиотеке нет и путь пропал. Откройте файл снова через **Открыть**.

**Книга не открывается.** Нужен EPUB, FB2 (в том числе в ZIP), TXT или Markdown. Повреждённый EPUB часто не читается.

**Словарь молчит.** Проверьте, что он выбран для этой книги (`D`) и слово совпадает со статьёй (регистр и окончания могут мешать).

**Порт занят.** boo сам возьмёт свободный порт. Адрес смотрите в консоли.

**Пропали данные.** Смотрите папку `%AppData%\boo` (`state.json`). Восстановление — из экспорта или из блока «Удалённое», если книгу только что стёрли.

boo принимает запросы только с этого компьютера. Открывать адрес из сети не нужно и не получится.
