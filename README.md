# boo

Локальная читалка книг: EPUB, FB2, TXT и Markdown. Данные живут на компьютере, сервер слушает только `127.0.0.1`. На Windows открывается своё окно (WebView2); на других системах — браузер.

Интерфейс на русском. Руководство для читателя — кнопка **Руководство** в приложении (клавиша `F1`) или файл [docs/user-guide.md](docs/user-guide.md).

## Возможности

- Полка, рабочие пространства и списки для чтения
- Прогресс, закладки, цветные выделения и заметки к фрагментам
- Описание и большая заметка на книгу, список дел с датой
- Поиск по названиям на полке и по тексту книги, оглавление, отметка прочитанных глав
- Словари (DSL, XDXF, JSON, TXT/TSV) — перевод по наведению
- История сессий, отметок и времени чтения, отмена удаления книги / закладки / заметки
- Экспорт и импорт всей библиотеки ZIP-архивом
- Темы `dark` / `sepia` / `light`, отдельные шрифты для текста и интерфейса, свой фон стартового экрана

## Требования

- Go 1.24+
- Windows: [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) для окна приложения
- На Linux и macOS окно не собирается — используйте `-web` или браузер по умолчанию

## Установка на Windows

Соберите setup и запустите его:

```powershell
powershell -File scripts\build-installer.ps1
.\dist\boo-setup.exe
```

Установка для текущего пользователя, без прав администратора. По умолчанию программа попадает в `%LocalAppData%\Programs\boo`, ярлык — в меню «Пуск». EPUB и FB2 можно открывать двойным щелчком.

Тихая установка: `.\dist\boo-setup.exe -silent`. Удаление — из списка программ Windows или `uninstall.exe` в каталоге установки. Папка `%AppData%\boo` с книгами и заметками при удалении не трогается.

Если WebView2 нет, установщик предупредит; читалку всё равно можно запустить с флагом `-web`.

## Сборка и запуск

```bash
go test ./...
go build -o boo.exe .
.\boo.exe
.\boo.exe книга.epub
.\boo.exe -demo
.\boo.exe -web
.\boo.exe -no-open -port 7474
```

| Флаг | Смысл |
| --- | --- |
| `-port` | Порт (по умолчанию `7474`; если занят — любой свободный) |
| `-web` | Открыть в браузере, не в окне |
| `-no-open` | Только сервер, без окна и браузера |
| `-demo` | Сразу открыть встроенную демо-книгу «Записки на полях» |
| путь | Файл `.epub`, `.fb2`, `.zip` (FB2), `.txt`, `.md` |

Без аргумента boo поднимает последнюю книгу из текущей полки, если файл ещё доступен.

## Где лежат данные

Каталог конфигурации ОС + `boo`:

- Windows: `%AppData%\boo`
- macOS / Linux: `~/.config/boo` (или аналог `os.UserConfigDir`)

| Путь | Содержимое |
| --- | --- |
| `state.json` | Пространства, полка, прогресс, закладки, заметки, UI |
| `library/` | Копии открытых файлов |
| `covers/` | Обложки |
| `dictionaries/` | Файлы словарей |
| `webview/` | Профиль WebView2 (только Windows) |

Импорт архива **заменяет** текущую библиотеку, а не дополняет её.

## Архитектура

```
main.go                 флаги, embed web/, старт HTTP, окно или браузер
internal/open           определение формата → единый epub.Book
internal/epub           EPUB + общая модель книги, санитайз HTML, поиск
internal/fb2            FB2 и FB2.zip → epub.Book
internal/txt            TXT / MD → главы по заголовкам
internal/server         localhost API и раздача UI
internal/store          JSON-хранилище, undo, export/import
internal/dict           разбор и lookup словарей
internal/desktop        окно WebView2 (windows) / заглушка (!windows)
web/                    index.html, app.js, styles.css
```

Все форматы приводятся к `epub.Book`. Ключ книги: `id:` + идентификатор файла или `file:` + хеш пути, названия и размера.

HTTP доступен только с loopback (`withLocalhost`). Ресурсы главы отдаются через `/res` — только изображения и шрифты.

Состояние UI одно: `GET /api/state`. Мутации обычно возвращают обновлённый state или срез (закладки, todos, history).

## Разработка

- Язык интерфейса и сообщений об ошибках — русский.
- Тесты рядом с пакетом: `*_test.go`. После изменений в парсерах, store или API гоняйте `go test ./...`.
- Фронтенд без сборщика: правки в `web/` попадают в бинарник через `//go:embed all:web`.
- Не добавляйте сетевые зависимости и удалённые сервисы. Приложение офлайн.
- Новые поля store — с миграцией в `store.Open` / `migrateWorkspaces`, без поломки старого `state.json`.
- Версии — SemVer, журнал — [CHANGELOG.md](CHANGELOG.md).
