# Статистика чтения

## Зачем

По записям таймера видеть, сколько времени ушло на чтение: за сегодня, неделю, месяц и всего — по всей полке и по одной книге.

## Что сделать

На стартовом экране показать суммарное время по всем книгам текущего пространства. В открытой книге — те же периоды только по ней.

## Готово когда

- На полке видны сегодня, неделя, месяц и всего по записям таймера всех книг пространства.
- В книге можно открыть ту же сводку по этой книге.
- Время берётся из журнала таймера, а не из текущего отсчёта.
